# CloudRunner

CloudRunner is a Windows desktop application for launching supported executable files on a cloud Windows computer and viewing the remote desktop.

## Download

Visit the [GitHub Releases page](https://github.com/greatPHPer/CloudRunner-Releases/releases) for published builds.

## Requirements

- Windows x64
- Microsoft Edge WebView2 Runtime
- Internet connection
- A valid CloudRunner activation

## Security

CloudRunner uses a backend service for cloud operations. Do not put API keys, administrator tokens, or private credentials in this repository.
